# CAMI INDUMENTARIA

Sitio estático listo para GitHub Pages.

## Publicar
1. Subí `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
2. GitHub > Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: `main` y carpeta `/(root)`.
5. Guardá y esperá a que GitHub publique el sitio.

Las imágenes actuales son placeholders. Después se pueden reemplazar por fotos reales sin cambiar la estructura.
