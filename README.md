# CAMI INDUMENTARIA

Sitio web estático para tienda de indumentaria femenina, listo para publicar con GitHub Pages.

## Archivos
- `index.html`: estructura principal.
- `styles.css`: diseño responsive para PC y celular.
- `script.js`: productos, buscador, ordenamiento y carrito con localStorage.

## Publicar en GitHub Pages
1. Crear un repositorio nuevo en GitHub.
2. Subir `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. Ir a **Settings > Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Elegir la rama `main` y la carpeta `/root`.
6. Guardar y esperar a que GitHub genere el enlace.

## Cambiar fotos
En este primer borrador se usan placeholders. Cuando tengas las fotos, se pueden agregar a una carpeta `img/` y reemplazar los bloques `.placeholder-image` por imágenes reales.

## Importante
Los precios y nombres de productos son demostrativos. Cambialos desde el array `products` en `script.js`.
